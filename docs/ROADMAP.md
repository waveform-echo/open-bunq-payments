# Roadmap

Possible future work, not current capability:

- true recurring/mandate lifecycle when supported by an appropriate bunq payment contract;
- refunds with provider and commerce-platform reconciliation;
- additional adapters (GiveWP, Easy Digital Downloads, PMPro direct one-time gateway, forms/donation plugins);
- more native SureCart client-side extension points if/when stable public hooks replace the compatibility redirect helper;
- WordPress.org packaging/translation pipeline;
- automated integration tests against disposable WordPress/WooCommerce/SureCart environments;
- multisite-specific policy controls.

Pull requests must not turn a one-time RequestInquiry into fake subscription support.
